**[GitHub Copilot 云智能体](https://docs.github.com/copilot/concepts/agents/cloud-agent/about-cloud-agent)** 可在云端异步处理工作。你在 GitHub 上分配任务后，云智能体便会在后台执行：探索存储库、进行更改并创建拉取请求，让你可以继续处理其他工作。

在这些练习中，你将添加云智能体要遵循的自定义指令，然后分配 GitHub 议题并让它实现需求。你还将审查和使用自定义智能体、在智能体仪表板中监控并引导会话，最后审查它创建的拉取请求并迭代改进结果。

## 先决条件

参加本研讨会前，请确保具备以下条件：

- [ ] 拥有有效 **Copilot Student、Pro、Pro+、Business 或 Enterprise** 计划的 GitHub 帐户
- [ ] 已为帐户或组织启用 Copilot 云智能体

> [!TIP]
> 没有付费计划？通过 [GitHub Education][callout-student-plan-education]，经验证的学生可以免费使用 GitHub Copilot。**Copilot Student** 计划包含本研讨会使用的智能体、MCP、代码审查和 Copilot CLI 功能，可用于完成所有练习。

[callout-student-plan-education]: https://github.com/education/students

> [!NOTE]
> 除 Copilot Free 外，所有计划（**Copilot Student、Pro、Pro+、Business 和 Enterprise**）均可使用云智能体。对于 Copilot Business 或 Enterprise，管理员必须为组织启用此功能。

> [!NOTE]
> 本练习系列不涉及 MCP。要了解如何将 MCP 服务器与 Copilot 配合使用，请参阅 [CLI 练习系列](../cli/)或 [VS Code 练习系列](../vscode/)。
