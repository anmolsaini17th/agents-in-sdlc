フィルター機能の実装、指示の更新、スキルの更新、品質保証 (QA) プロファイル、テストを 1 つのブランチに保存しました。これらをまとめてレビューし、プル リクエストを作成します。星評価のプル リクエスト (PR) は自分でマージしましたが、今回は **Agent Merge** にプロセスの管理を任せます。

> [!NOTE]
> 通常は、機能、指示の更新、スキルの更新、QA エージェントを複数の PR に分けます。ワークショップを簡潔に進めるため、フィルター機能と品質ワークフロー全体を 1 つのセッションとブランチで進め、すべての作業をこの PR にまとめました。

このレッスンでは、次の操作を行います。

- Agent Merge の概要と、マージのライフサイクルを自動化する仕組みを確認します。
- 機能の PR 全体と検証の証拠を確認します。
- レビュー後にのみ Agent Merge を許可し、PR のマージを確認します。

## シナリオ

フィルター機能のワークフロー全体を通じて、Copilot を使って機能を計画、実装、検証しました。Tailspin Toys は、マージの承認を開発者の管理下に置きながら、残りの PR 作業を自動化したいと考えています。

## Agent Merge の概要

**Agent Merge** は、GitHub Copilot app でプル リクエストをマージするまでに必要な残りの作業を自動化します。有効にすると、アプリのセッションが PR を読み取り、失敗した継続的インテグレーション (CI) チェックの修正、レビュー コメントへの対応、必要に応じたリベースなど、マージを妨げている問題に対処します。GitHub が許可すると PR をマージします。バックグラウンドで動作し、アプリを再起動しても継続し、PR がマージされると自動的に無効になります。

ここまでは、自分で **Merge pull request** を選択していました。Agent Merge にその作業を任せることもできますが、コードの編集やマージには、引き続き明示的な許可が必要です。マージを許可する前に、Agent Merge が実行できる操作と作業内容をレビューしてください。

## Agent Merge で PR を管理する

コードの作成とレビューが完了したので、Agent Merge に PR の作業を管理させます。

1. エージェント ピッカーで **Default agent** を選択します。
2. **Create PR** の横にあるドロップダウンを選択します。
3. **Agent Merge** を選択します。ボタンが **Agent Merge** に変わります。
4. **Agent Merge** ボタンを選択してプロセスを開始します。ドロップダウンの項目を選択しただけでは開始されません。

Agent Merge のプロセスが始まると、次の処理を行います。

- タイトルと説明を付けてプル リクエストを作成します。
- Issue からセッションを開始した場合は、説明本文で関連する Issue を参照します。
- リベースを行うか、ターゲット ブランチとのマージ競合に対処します。
- CI を監視し、すべてのチェックが成功することを確認します。
- 他の開発者や Copilot コード レビューからのフィードバックがないか PR を監視し、コメントを解決するための更新を行います。
- すべてのチェックが成功した後、PR を自動的にマージすることもできます。

すべてのチェックが成功したら、Agent Merge に PR のマージも任せましょう。

5. マージを許可する前に、PR の差分と検証の証拠をレビューします。
6. **Agent Merge** の横にあるドロップダウンを選択します。
7. **Merge pull request** の横にチェックが付いていることを確認します。
8. エージェントに明示的にマージを依頼します。

    ```plaintext
    Merge the PR once all required checks and approvals pass. Do not bypass repository protections.
    ```

9. 進行状況を確認し、報告された阻害要因を解決します。続行する前に PR の状態が **Merged** になっていることを確認します。マージの許可を有効にしたことや、エージェントが作業中であることは、マージ完了の確認にはなりません。

> [!IMPORTANT]
> Agent Merge は、リポジトリの保護や権限不足を回避しません。続行する前に、これらの阻害要因を解決してください。

- 機能の PR 全体と検証の証拠を確認しました。
- レビュー後にのみ Agent Merge を許可し、PR がマージされたことを確認しました。
