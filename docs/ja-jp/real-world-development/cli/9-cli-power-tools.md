多くの CLI ツールと同様に、GitHub Copilot CLI には対話に使えるスラッシュ コマンドが数多く用意されています。これらのコマンドを使うと、高度な機能、内部情報、追加の構成オプションを利用できます。これまでに `/diff`、`/mcp`、`/skills`、`/agent`、`/pr` などのコマンドを使いました。ほかの便利なコマンドも確認しましょう。

このレッスンでは、次の操作を行います。

- `/context` と `/compact` で、Copilot が会話のコンテキストを管理する方法を確認します。
- `/model` で使用可能なモデルを確認します。
- `/share` でセッションをエクスポートまたは共有する方法を学びます。
- 並列作業、worktree、クラウド エージェントへの委任に使う任意のコマンドを確認します。

## シナリオ

CLI の主なワークフローが終わりました。ここでは、コンテキストの管理、モデルの切り替え、セッションの共有、[Copilot クラウド エージェント][about-cloud-agent]への任意の委任など、追加機能を確認します。

## Copilot CLI のコンテキストを確認する

大規模または複雑なタスクに取り組むと、モデルの最大コンテキスト ウィンドウに達する場合があります。Copilot CLI は必要に応じて会話を自動的に圧縮します。スラッシュ コマンドを使って、自分で確認したり圧縮したりすることもできます。

1. Codespace に戻ります。Copilot CLI をまだ起動していない場合は、リポジトリのルートから起動します。
2. 次のコマンドを入力します。

   ```plaintext
   /context
   ```

3. モデル、現在のトークン使用量、システム命令、ツール、メッセージ、空き領域に分割されたコンテキストを確認します。
4. 会話を圧縮します。

   ```plaintext
   /compact
   ```

5. もう一度 `/context` を入力して結果を比較します。会話が短い場合は、大きな違いが見られないこともあります。

> [!NOTE]
> Copilot CLI は、コンテキスト ウィンドウが埋まると自動的に圧縮します。自分でタイミングを選ぶ場合は `/compact` を使います。関係のないタスクに切り替えて新しい会話を始める場合は、`/clear` または `/new` を使用します。

## モデルを選ぶ

モデルごとに得意分野が異なり、開発者の好みもさまざまです。Copilot CLI では、使用できるモデルを一覧表示して選択できます。

1. 次のコマンドを入力します。

   ```plaintext
   /model
   ```

2. 使用可能なモデルと使用状況の情報を確認します。
3. 現在のモデルを維持するか、別のモデルを選択するか、<kbd>Esc</kbd> を押して一覧を閉じます。

## セッションを共有する

チームで連携し、学んだことを共有すると、AI ツールの活用方法を互いに改善できます。`/share` を使うと、セッションを Markdown または HTML ファイルにエクスポートしたり、共有リンクを作成したり、GitHub gist を公開したりできます。

1. `/help` を入力し、インストール済みのバージョンに表示される `/share` のオプションを確認します。
2. セッションを共有する場合は、`/share file` によるローカルな Markdown エクスポートなど、目的に合う方法を選択します。
3. エクスポートした内容を送信または公開する前に確認します。セッションのエクスポートには、プロンプト、応答、プロジェクトの詳細が含まれる場合があります。

リンクや gist の公開は任意です。チームが共有を予定していないリポジトリや会話の内容は公開しないでください。

## オプション: 作業を拡張または委任する

ワークショップの主要な内容は完了しました。Copilot CLI には、大規模なタスクに使える次のコマンドもあります。

- `/fleet` は、独立したサブタスクを複数のサブエージェントに分割し、並列実行できます。
- `/worktree` は、別のタスク用に分離された Git worktree を作成できます。
- `/delegate` は、タスクを Copilot クラウド エージェントに送信できます。クラウド エージェントは非同期で作業し、プル リクエストを開く場合があります。

追加の worktree やリモート作業が発生するため、これらのコマンドは任意です。試すときは、範囲の明確な新しいタスクから始めて、通常のワークフローと同じように結果をレビューしてください。非同期エージェントによる作業について詳しく知りたい場合は、[クラウド エージェントのワークショップ][cloud-workshop]に進んでください。

- `/model` で使用可能なモデルを確認しました。
- `/share` でセッションをエクスポートまたは共有する方法を学びました。
