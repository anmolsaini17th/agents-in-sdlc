GitHub Copilot をエージェント モードで使うと、コードベースを調べ、変更を提案し、ファイルを編集し、コマンドを実行するなど、自律的に作業します。作業は手元のマシンでリアルタイムに進むため、VS Code の Copilot Chat では、各ツール呼び出しやファイル編集の状況を確認できます。差分をインラインで確認し、個々の変更を承認または却下できます。また、エディターを離れずに追加のプロンプトを送って会話を導き、作業を調整したり広げたりできます。

この演習では、次の操作を行います。

- アクセシビリティ エージェントの作業をリアルタイムで監視します。
- 提案されたファイル編集を確認して承認します。
- セッションの途中でエージェントに指示し、ハイ コントラスト モードに加えてライト モードを追加します。

## シナリオ

[演習 4][previous-lesson]で使ったアクセシビリティ カスタム エージェントが、ハイ コントラスト モードを実装しています。作業中、デザイン チームから追加の依頼がありました。既定のテーマが暗すぎると感じるユーザー向けに、ライト モードの切り替え機能も追加したいとのことです。新たに会話を始める代わりに、現在のセッションを導いて作業を拡張します。

## Copilot の進行状況を監視する

Copilot Chat ビューには、エージェントが行う各手順が表示されます。調べているファイル、実行するコマンド、提案する編集を確認できます。ファイルの編集内容は、差分と **Keep** / **Undo** の操作が付いた状態でチャットにインライン表示されます。

1. 演習 4 で使った Copilot Chat ビューに戻ります。
2. エージェントの作業中にチャットをスクロールし、ツール呼び出しを確認します。ファイルの読み取りや編集、実行を求めるターミナル コマンドが表示されます。
3. エージェントがファイルの編集を提案すると、差分がインライン表示されます。
    - 変更を承認するには **Keep** を選択します。
    - 変更を取り消し、エージェントに再度作業させるには **Undo** を選択します。
4. チャット上部の **Files changed** の表示を開くと、このセッション中にエージェントが変更したすべての作業ファイルを確認できます。

> [!NOTE]
> ツール呼び出しで許可が必要な場合 (たとえば、ターミナル コマンドの実行など)、エージェントは一時停止し、**Allow** の確認を表示します。内容を確認し、許可してもよいコマンドだけを承認してください。

5. エージェントがハイ コントラスト モードの実装を終えるまで待ちます。最後に、行った変更をまとめたメッセージが表示されます。

## エージェントにライト モードの追加を指示する

ハイ コントラスト モードを実装したら、同じ会話でライト モードの切り替え機能を追加します。同じチャット セッションを続けるため、エージェントは前の作業で得たコンテキストを保持しています。変更したコンポーネント、適用したスタイル、設定した local storage のパターンなどです。

1. Copilot Chat の入力欄に次の追加プロンプトを送信します。

    ```plaintext
    Nice work! Now add a light-mode toggle alongside the high-contrast toggle. Light mode should follow the same pattern — persist via local storage and be accessible from the same area of the UI. The user should be able to enable high-contrast and light mode independently.
    ```

2. エージェントは、すでに行った変更を調べ、ライト モードの追加を提案します。
3. ハイ コントラスト モードのときと同様に、新しい編集内容を確認し、各差分で **Keep** または **Undo** を選択します。
4. エージェントが意図しない方向に進んだ場合 (たとえば、好みと異なる方法でトグル UI をリファクタリングしようとした場合) は、チャット入力欄の横にある **Stop** ボタンで停止し、明確な指示を追加で送信します。

> [!TIP]
> 進行中のセッションに指示するほうが、最初からやり直すよりも速くなります。追加プロンプトで調整を依頼できます (「CSS を簡潔にして、セレクターの重複ではなく CSS 変数を使ってください」)。方向を修正したり (「トグルを 3 つにせず、ライト モードを既存の設定パネルに追加してください」)、作業範囲を広げたり (「両方のトグルにキーボード ショートカットも追加してください」) することもできます。

## 作業ファイルをレビューする

変更をコミットする前に、エージェントが編集したファイルを確認します。

1. VS Code で **Source Control** ビューを開きます。
2. 変更されたファイルの一覧を確認します。Astro コンポーネント、スタイル、関連テストなどが更新されているはずです。
3. 変更されたファイルをいくつか開き、差分を確認します。カスタム エージェントのアクセシビリティ パターンが反映されていることを確認します。ARIA 属性、キーボード ナビゲーション、セマンティック HTML、local storage による設定の保持などです。
4. 内容に問題がなければ、Source Control パネルから変更をステージしてコミットします。次のレッスンで公開します。

## まとめと次のステップ

この演習では、Copilot Chat のエージェント モードを使って、進行中のセッションを監視して指示しました。ファイルの編集を確認しながら承認または却下し、会話のコンテキストを維持したまま追加プロンプトを送り、作業を広げました。

このレッスンでは、次の操作を行いました。

- エージェントの作業をリアルタイムで監視しました。
- 個々のファイル編集を承認または却下しました。
- 追加プロンプトを使って、作業の途中でセッションを導きました。
